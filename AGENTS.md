# AGENTS.md

Guidance for AI coding agents and contributors. `CLAUDE.md` imports this file, and `.github/copilot-instructions.md` adds the review checklist.

## Language

- All deliverables are written in **English**: commit messages, PR/Issue titles and bodies, review comments, code comments and JSDoc, and documentation (`README.md`, `AGENTS.md`, etc.).
- Runtime messages (logs and error messages) are English.
- Exceptions (keep as is): quotations, technical identifiers, generated files, and external source text.
- Do not rewrite Git history to change the language of past commits.

## Overview

`@book000/node-utils` is a personal TypeScript utility library published to npm (single package, not a monorepo). Only `dist/` is published (`files` in `package.json`).

- `Logger` (`src/logger.ts`): winston wrapper with console and daily-rotated file output, `text` / `ndjson` file formats, and a per-category instance cache. Registers `unhandledRejection` / `uncaughtException` handlers on import.
- `ConfigFramework` (`src/config.ts`): abstract base class for a JSONC configuration file. The path comes from `CONFIG_PATH`, `CONFIG_FILE` or the constructor argument. Subclasses define validation rules.
- `Discord` (`src/discord.ts`): sends and edits messages through a Bot or a Webhook (embeds, link buttons, files, flags).
- Sentry (GlitchTip) integration: `SentryTransport` (`src/sentry-transport.ts`) is added to the Logger transports when `SENTRY_DSN` is set. `ErrorReporter` (`src/error-reporter.ts`) is an explicit opt-in static API.
- `src/sentry/`: internal helpers (`sentry-client.ts`, `sentry-release.ts`) marked with `@ctix-exclude`, so they are not exported from `src/index.ts`.
- `src/examples/`: usage examples (not part of the library). `src/__tests__/`: Jest tests.

`src/index.ts` is generated by ctix (`pnpm ctix`, also run by `pnpm build`). Do not edit it by hand.

## Commands

```shell
pnpm install   # install dependencies
pnpm build     # clean -> ctix (regenerate src/index.ts) -> tsc -p tsconfig.build.json
pnpm test      # jest with coverage
pnpm lint      # prettier --check + eslint + tsc
pnpm fix       # prettier --write + eslint --fix
pnpm example   # run src/examples/main.ts (the Discord example needs DISCORD_WEBHOOK_URL)
```

Run `pnpm lint` and `pnpm test` before committing. The package manager is pnpm (version pinned by `packageManager` in `package.json`); the Node.js version is in `.node-version`. CI uses the reusable workflow `book000/templates/.github/workflows/reusable-nodejs-ci-pnpm.yml`. `prepublishOnly` runs `lint` and `prepare` runs `build`.

## Conventions

- Prettier (`.prettierrc.yml`: no semicolons, single quotes, 2-space indent, width 80) and ESLint (`@book000/eslint-config`).
- TypeScript strict mode. Do not enable `skipLibCheck`; avoid `any`. Path alias `@/*` maps to `src/*`.
- Write JSDoc for exported functions, classes and interfaces. Comments explain intent and constraints, not what the code already says.
- Configurable values are overridable by environment variables (see `Logger` and `ConfigFramework`). Document new variables in the `README.md` tables.
- Tests live in `src/__tests__/*.test.ts` (Jest + ts-jest). Mock external dependencies (winston, Sentry, `fetch`, moment-timezone); tests never touch the network. Add tests for new features.
- Update `README.md` when behavior or usage changes, and this file when commands or structure change.
- Commits follow [Conventional Commits](https://www.conventionalcommits.org/); branches follow [Conventional Branch](https://conventional-branch.github.io) short form (`feat/...`, `fix/...`, `docs/...`).
- Do not push commits to Renovate PRs.
- Never commit secrets or credentials, and never log them.
